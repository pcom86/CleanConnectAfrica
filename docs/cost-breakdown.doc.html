15. Cost Optimization Tips

  • Use the Azure free account (R 3,000 credits for 30 days) to test the full architecture at zero cost
  • Start with Burstable B1ms for PostgreSQL; upgrade to General Purpose only when CPU consistently exceeds 60%
  • Use Azure Static Web Apps free tier — includes custom domains and 250 GB bandwidth
  • Keep Redis on Basic C0; upgrade only when you need > 250 MB or clustering
  • Set Container Apps max replicas to 1 during launch; scale up only with traffic
  • Use Log Analytics daily cap to limit ingestion and control telemetry costs
  • Start with Google Maps free tier ($200 credit) before paying for Mapbox
  • Use AWS SES for email (cheapest at scale) and defer SMS until you have active customers
  • Negotiate Ozow fees once you have transaction volume data — volume typically drives discounts
