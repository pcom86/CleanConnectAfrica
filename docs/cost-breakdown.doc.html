Cost Optimization Tips

  • Use the Azure free account (R 3,000 credits for 30 days) to test the full architecture
  • Start with Burstable B1ms for PostgreSQL; upgrade only when CPU exceeds 60%
  • Use Azure Static Web Apps free tier — includes custom domains and 250 GB bandwidth
  • Keep Redis on Basic C0; upgrade only when you need > 250 MB
  • Set Container Apps max replicas to 1 during launch; scale up with traffic
  • Use Log Analytics daily cap to limit ingestion and control telemetry costs
  • Defer email/SMS integration until you have active customers (in-app notifications are built in)
